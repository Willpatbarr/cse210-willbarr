The quickest way to see everything that the program does is to 
1. type any text in as a name
2. set difficulty to 1
3. continue hitting enter till you are presented with the option to stay and fight or run
4. always choose to run as it still can result in fighting
5. if you lose a fight press enter to play again in order to view how it ends
6. if you win a fight choose yes on picking up any items
7. repeat until 0 meters remain and you reach the castle
